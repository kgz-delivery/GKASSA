# Flash Payment Reader — открыть в Android Studio

Это отдельное Android-приложение-читалка. Оно получает уведомления только от Optima, сохраняет их локально до отправки, скачивает regex с backend и отправляет платежи в API бота.

## Открыть проект

1. Установи Android Studio, если её ещё нет.
2. Запусти Android Studio и нажми **Open**.
3. Выбери эту папку `android-reader` — не корень Telegram-бота.
4. Если Android Studio предложит скачать Gradle, Kotlin или Android SDK, нажми **Download/Install** и дождись окончания Sync.
5. Нажми зелёную кнопку **Run ▶**. Для запуска на телефоне подключи его USB-кабелем и подтверди запрос **Allow USB debugging**. Можно сначала использовать встроенный эмулятор.

Внутри приложения укажи URL Render вида `https://<имя>.onrender.com`, постоянный ID телефона и `PAYMENT_DEVICE_TOKEN`, затем нажми **Сохранить настройки**. Нажми **Разрешить чтение уведомлений** и включи доступ для Flash Payment Reader в настройках Android.

Исходный проект backend находится на уровень выше (`../src`); Android-приложение не заменяет Telegram-бота и не запускает зачисление букмекеру само. Зачисление выполняет backend.
